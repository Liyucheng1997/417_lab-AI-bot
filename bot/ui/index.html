我的手机
用 Wi-Fi 连接手机手机和电脑连同一个 Wi-Fi 就行，不用数据线
  1. 打开手机的开发者选项（只需一次）：设置 → 关于手机 → 连续点「版本号」7 次华为 / 荣耀：设置 → 关于手机 → 版本号；小米：设置 → 我的设备 → 全部参数 → OS 版本
  2. 开发者选项里打开 无线调试，勾上「始终允许在此网络上使用」华为 / 荣耀的开发者选项在「系统和更新」里
  3. 点 使用二维码配对设备，扫上面的码，几秒后自动连上

只要配对一次。以后手机在这个 Wi-Fi 里开着无线调试，Bot 会自己连上，点「投屏」就行。

使用配对码配对扫不了码时用：无线调试 → 使用配对码配对设备，把弹窗里的 IP 地址和端口、配对码填进来
直接连接配对过的手机：填「无线调试」页面上方显示的 IP 地址和端口

Android 10 及以前、部分鸿蒙 2–4 的手机开发者选项里没有「无线调试」。这种手机需要插一次数据线打开无线端口，之后拔掉线一直用 Wi-Fi（手机重启后要再插一次）：

  1. 开发者选项里打开 USB 调试小米还要打开「USB 调试（安全设置）」
  2. 插上数据线，手机上弹出「允许 USB 调试吗？」点允许
  3. 上面出现手机后，点它的「切换到无线」，然后拔掉数据线

纯血鸿蒙（HarmonyOS NEXT / 5）不兼容安卓调试，暂时不支持。

iPhone / iPad
投屏设置下次投屏生效（置顶马上生效）
投屏窗口里的小技巧
  • 右键 返回，中键 回到桌面，滚轮上下滑动
  • 把文件拖进窗口就传到手机的 Download 文件夹；拖 APK 进去是安装
  • 点一下手机里的输入框，就能用电脑的输入法直接打字，中文也行
  • 手机上复制的文字，电脑上直接能粘贴；电脑上复制后在窗口里按 Ctrl+V 粘贴到手机
  • Alt+F 全屏，Alt+R 横竖屏，Alt+O 手机熄屏（电脑上照常用），Alt+Shift+O 亮屏
  • 窗口旁边的工具条：截图（自动复制）、音量、锁屏、置顶，以及让 Bot 操作手机
